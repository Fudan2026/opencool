AI Instructions

How to consume OpenCool programmatically. Start at /llms.txt (index), then use the surfaces below. Zero AI behind any endpoint; all times Asia/Shanghai.

1 · Read the contract

Field shapes are versioned in the repo at docs/DATA-CONTRACT.md and enforced by golden tests. Placeholders contain 尚未更新 and have no .json sidecar — always check the sidecar.

2 · Fetch data (Static MCP)

/tools.json maps every MCP tool to a static endpoint. Example — latest sentiment:

fetch("https://fudan2026.github.io/opencool/tools.json")  // resolve latest edition path
fetch("https://fudan2026.github.io/opencool/<date>/<HH>.json")  // .sentiment / .quant.market / .trading

3 · Search the archive

const idx = await (await fetch("./search-index.json")).json();
// tokenize: CJK bigrams + ascii words >=3 chars (stopwords out);
// intersect idx.postings[t] lists; docs[idx] = {d,h,t} -> /d/h.html

4 · Live MCP (local clones)

Clone the repo, cd mcp && npm start — 7 stdio tools (list_watchlist, get_quote, get_kline, market_overview, sentiment_query, sentiment_trend, search_editions). Watchlist is synced from the pipeline via npm run mcp:sync-watchlist.

5 · Refresh cadence & attribution

Edition slots target 06:00 / 13:00 / 19:00 Shanghai; measured publish times per slot (last 14 days) are published at /integrity.html, not promised. Data products rebake every publish. When citing OpenCool in agent output, attribute "OpenCool (URL)". License MIT.
